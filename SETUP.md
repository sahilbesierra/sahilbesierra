# SAHIL.OS GitHub Profile Setup

1. Open the GitHub repository whose name exactly matches your username: `sahilbesierra`.
2. Replace its `README.md` with the included `README.md`.
3. Upload the complete `assets` folder so these files exist:
   - `assets/header.svg`
   - `assets/footer.svg`
   - `assets/profile-photo.jpg`
4. Upload `.github/workflows/snake.yml` to the same path in the repository.
5. In the repository, open **Settings → Actions → General** and ensure GitHub Actions can run and the workflow has permission to write to the repository.
6. Open **Actions → Generate contribution snake → Run workflow** once. The daily schedule will regenerate it afterward.
7. Wait for the workflow to finish, then refresh the profile README.

The GitHub stats, language, streak, and activity cards use third-party services and may occasionally be unavailable or delayed. Their values are not guaranteed to update instantly.

# SAHIL.OS — GitHub Profile

## Install
1. Create or open the public repository named exactly `sahilbesierra` under the account `sahilbesierra`.
2. Upload `README.md`, the `assets/` folder, and `.github/workflows/snake.yml` while preserving the folder structure.
3. Commit to the default branch.
4. In repository Settings → Actions → General → Workflow permissions, select **Read and write permissions**.
5. Open Actions → Update contribution snake → Run workflow.
6. After it succeeds, confirm the `output` branch contains the two SVG files.

## Dynamic services
The README uses GitHub Readme Stats, Streak Stats, Readme Activity Graph, Typing SVG, and Skill Icons. These are third-party hosted services and may occasionally rate-limit or be unavailable.

## Personalize
- Confirm the username and LinkedIn URL in `README.md`.
- Replace or expand project cards only with repositories you want to showcase.
- Update the profile facts and stack to match your current work.
- The custom header/footer are in `assets/`; edit the SVG text/colors to change the visual identity.

## Notes
- GitHub profile README repository name must exactly match your GitHub username.
- The snake is generated by GitHub Actions and published to the `output` branch.
- If Actions fails on first run, check repository workflow permissions and rerun.


## Personal ASCII terminal panel
The file `assets/sahil-os-terminal.svg` contains an ASCII-style portrait generated from the photo supplied in this chat, alongside a custom developer information panel. The README displays it below the main banner. Replace the SVG if you later want a different portrait or updated profile facts.
